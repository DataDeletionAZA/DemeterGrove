# DemeterGrove · 暮色小院

一个运行在 Mac 上的像素风桌宠与专注小院。当前版本 **0.13.0**，适用于 Apple 芯片 Mac、macOS 14 或更新版本。

桌宠可以拖动，计数旁的按钮打开功能菜单。功能窗口附着在桌宠旁，带返回按钮。桌宠拖到屏幕底部会吸附，并隐藏下方计数和计时牌；移离底部后重新显示。管理窗口通过书房、农场、厨房、商店和炼金室进入各项功能；「地图」打开小院，并从路牌打开平面户外地图，前往钓鱼与探险。

## 功能

- 任务清单与四象限、自定义类型、可选截止日期；周期计划的每期记录独立保存，上一期未完成时下一期照常出现。
- 番茄钟、正计时、倒计时，选择现有任务、新建任务或本次专注名称。结束后可补充感想、心情、任务完成状态与改期；专注片段、暂停和休息分别记录，旧记录未采集的信息显示未知。
- 日程汇集安排、任务、日记、习惯审核、专注与休息记录，按日期查看材料和评语；独立周／月历日记支持自定义心情。
- 习惯周历以每日大卡展示各项状态，点击日期查看详情，也可切换月历。任务和习惯支持每 N 天／周／月、周内多选，以及连续执行／休息、逐日自定的循环，创建时显示逐日预览。
- 每项任务或习惯拥有独立激励语库，随机轮换，整库用尽前不重复。提醒滚动安排未来 30 天，应用运行时续排。
- 设置中可保存多个 AI 服务与模型预设，分别分配给任务激励语、习惯激励语、习惯审核与专注评价；支持 Responses 和 Chat Completions 接口与思考强度选择。密钥保存在 Mac 钥匙串。
- 激励语可选择 1～50 条及短、中、长，分批生成，实时显示正文接收进度；连续120秒没有新数据才超时。结果可编辑、勾选后加入文字库。表达预设包含可编辑提示词、可移动占位符、附加要求与可选的人物及用户设定。
- 专注评价由用户点按请求，并与原记录一同保存；修改记录后可重新评价。
- 当天习惯支持文字或照片材料审核，显示审核中、已通过或待补充。网络失败保留材料，可重试或取消；审核通过后保存记录与奖励；压缩照片、文字材料和评语可按日期回看，归档习惯保留历史。
- 累计签到奖励规则：每日一次铜币奖励，7／30／66／90 天里程奖励。审核通过才结算。
- 日期设置可选择时区与每日换日时间；跟随今天的日历会自动跨日，历史浏览保留所选日期。
- 周、月、年统计各自包含所选时段的专注、操作、日记、任务与习惯记录；一周从周一或周日开始可在设置中选择。
- 农场的生长阶段、种子柜、两种播种入口；厨房按食材组合和做法制作料理，配方随制作记录解锁；商店出售成品，未成交时可下架退回库存；料理柜按宽度排列1至4列，可按当前顺序一键补满空余栏位。每个场景提供独立库存窗口，分类查看原料、成品、种子、道具、服饰和货币。
- 场景使用统一画面区域并随窗口宽高调整，切换场景保留窗口大小。室内场景和野外场景分别通过双向箭头切换，农场及商店出口连接庭院。魔药选料台展示已选材料与制作结果。农场侧栏显示种子，书房侧栏汇总今日事项；户外地图显示各地点与解锁条件，湖畔提供渔具店。
- 专注经验、金银铜货币、工具升级、土地和店面扩建、钓鱼、冒险与魔药。
- 经授权后统计键盘按下和鼠标点击次数，不保存输入内容。桌宠计数牌点击后依次切换「目前」可兑换余额、「今日」次数和「总量」；每 10,000 次有效操作可兑换 1 铜币，兑换后扣除对应余额。
- 操作次数达到 100,000 后以万／亿简写，悬停可查看完整数字。
- 自制下拉选择、像素滚动条和滑块；短提示自动消失，鼠标悬停时暂停消失计时。
- 桌宠眼区互动包含眨眼后看向镜头的动作，头发外沿经过整理。
- 自动保存、保存状态显示、备份导入／导出。

## 使用

打开「暮色小院.app」后，拖动角色可以移动桌宠，点击计数旁的省略号打开菜单。菜单通过右上角的「X」关闭。开始专注后，计数下方显示实时计时。

在「设置」中开启操作计数，并在 macOS「系统设置 → 隐私与安全性 → 输入监控」中允许应用。系统要求重新打开时，按提示退出并重开。

数据保存在用户资料库的 `Application Support/Daygarden` 文件夹。设置中的「打开存档文件夹」可以直接前往；「导出备份」会生成包含日记和证据照片的数据文件。

### 设置习惯审核

1. 打开桌宠菜单中的「设置」，选择「AI 服务」。
2. 新建或选择一个预设，填写名称、API 地址、接口格式、模型和密钥，再点击「保存预设」。思考强度按所选模型支持的选项设置。
3. 在下方「习惯审核」右侧选择刚保存的预设。
4. 返回「习惯」，点开当天的打卡，填写文字或添加照片，点击「提交并审核」。只有当天的材料可审核；通过后的记录不重复结算奖励。

### 编辑 AI 表达

1. 打开「设置 → 表达与提示词」，新建或选择表达预设。
2. 选择激励语、习惯审核或专注评价，编辑对应模板；点占位符按钮可插入到光标位置。
3. 在「附加要求」填写语言、翻译格式等要求；人物设定与用户设定可留空。
4. 保存预设，并在相应功能右侧选择它。生成激励语时，也可以填写仅用于本次生成的附加要求。

## 从源码制作应用

需要 Xcode 命令行工具。打开「终端」，输入 `xcode-select --install` 并按回车，按系统提示完成安装；已经安装时无需重复操作。

1. 下载本仓库，在访达中解压。
2. 打开「应用程序 → 实用工具 → 终端」。输入 `cd` 和一个空格，把解压后的文件夹拖入终端，再按回车。这会把操作位置切换到该文件夹。
3. 输入 `zsh build.sh`，按回车。这会把源码制作成应用。
4. 完成后，在该文件夹中的 `build` 文件夹里打开「暮色小院.app」。

生成的 `build` 文件夹可删除后重新制作，不会删除存档。未经公证的自行构建应用，首次打开时可能需要在系统「隐私与安全性」设置中允许打开。

`build.sh` 可读取本机 `.build-local.env` 中的 `DAYGARDEN_SIGNING_IDENTITY` 和 `DAYGARDEN_BUNDLE_ID`，用于保持安装身份。默认使用项目标识和本机临时签名。

## 检查与版本

在上述终端位置输入 `bash test.sh`，会依次检查计时结算、交易、存档兼容、习惯奖励、保存失败处理、周月年统计、专注记录、库存、日历、屏幕位置和场景点击范围，并检查全部源码是否能够编译。测试使用临时存档，结束后自动清理。

源码位于 `Sources`，图像位于 `Resources`，规则检查位于 `Tests`。`Resources/Chibi` 保存桌宠姿势，`Resources/Game` 保存场景与食物，`Resources/Doll` 保存衣柜素材。

AI 功能需要在设置中填写服务地址、模型和密钥，再选择对应功能使用的预设。点击生成或提交审核时发送请求，定时提醒使用已保存的文字库。习惯审核会把习惯名称、所填写文字和所选照片发送给分配的服务；可在提交窗口查看接收地址。导出备份包含 AI 预设信息，不包含密钥。

版本号记录在 `Resources/Info.plist`，更新记录见 [CHANGELOG.md](CHANGELOG.md)，后续开发见 [ROADMAP.md](ROADMAP.md)。维护者提交当前版本后运行 `bash publish.sh`，检查通过后将源码与对应 `v版本号` 标签推送到远端。每个标签保留当时的源码快照。
