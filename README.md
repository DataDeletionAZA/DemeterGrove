# DemeterGrove · 暮色小院

一个运行在 Mac 上的像素风桌宠与专注小院。当前版本 **0.9.0**，适用于 Apple 芯片 Mac、macOS 14 或更新版本。

桌宠可以拖动，计数旁的按钮打开功能菜单。功能窗口附着在桌宠旁，带返回按钮。桌宠拖到屏幕底部会吸附，并隐藏下方计数和计时牌；移离底部后重新显示。管理窗口通过庭院、书房、农场、厨房和商店进入各项功能。

## 功能

- 任务清单与四象限、自定义类型、可选截止日期。
- 番茄钟、正计时、倒计时，选择现有任务、新建任务或本次专注名称。
- 日程、独立周／月历日记、自定义心情。
- 习惯周历以每日大卡展示各项状态，点击日期查看详情，也可切换月历；支持提醒和激励文字。
- 当天习惯的文字和照片材料保存在本机，当前处于待审核状态。
- 累计签到奖励规则：每日一次铜币奖励，7／30／66／90 天里程奖励。审核通过才结算。
- 统计可选择周、月和年份，汇总范围内的专注、操作、日记、任务与习惯记录，并保留累计统计。
- 农场的生长阶段、种子柜、两种播种入口；厨房按食材组合和做法制作料理，配方随制作记录解锁；商店出售成品。
- 场景随窗口宽高调整，地块、柜架和陈列位按宽度排列；双向箭头和门提供场景切换。魔药选料台展示已选材料与制作结果。
- 专注经验、金银铜货币、工具升级、土地和店面扩建、钓鱼、冒险与魔药。
- 经授权后统计键盘按下和鼠标点击次数，不保存输入内容。桌宠计数牌点击后依次切换「目前」可兑换余额、「今日」次数和「总量」；每 10,000 次有效操作可兑换 1 铜币，兑换后扣除对应余额。
- 操作次数达到 100,000 后以万／亿简写，悬停可查看完整数字。
- 自制下拉选择、像素滚动条和滑块；短提示自动消失，鼠标悬停时暂停消失计时。
- 桌宠眼区互动包含眨眼后看向镜头的动作，头发外沿经过整理。
- 本机自动保存和备份导入／导出。

习惯审核服务尚未接通，材料保持待审核状态，不会发放审核奖励。AI 料理建议属于后续方向；当前料理使用本机配方规则。

## 使用

打开「暮色小院.app」后，拖动角色可以移动桌宠，点击计数旁的省略号打开菜单。菜单通过右上角的「X」关闭。开始专注后，计数下方显示实时计时。

在「设置」中开启操作计数，并在 macOS「系统设置 → 隐私与安全性 → 输入监控」中允许应用。系统要求重新打开时，按提示退出并重开。

数据保存在用户资料库的 `Application Support/Daygarden` 文件夹。设置中的「打开存档文件夹」可以直接前往；「导出备份」会生成包含日记和证据照片的数据文件。

## 从源码制作应用

需要 Xcode 命令行工具。打开「终端」，输入 `xcode-select --install` 并按回车，按系统提示完成安装；已经安装时无需重复操作。

1. 下载本仓库，在访达中解压。
2. 打开「应用程序 → 实用工具 → 终端」。输入 `cd` 和一个空格，把解压后的文件夹拖入终端，再按回车。这会把操作位置切换到该文件夹。
3. 输入 `zsh build.sh`，按回车。这会把源码制作成应用。
4. 完成后，在该文件夹中的 `build` 文件夹里打开「暮色小院.app」。

生成的 `build` 文件夹可删除后重新制作，不会删除存档。未经公证的自行构建应用，首次打开时可能需要在系统「隐私与安全性」设置中允许打开。

`build.sh` 可读取本机 `.build-local.env` 中的 `DAYGARDEN_SIGNING_IDENTITY` 和 `DAYGARDEN_BUNDLE_ID`，用于保持安装身份。默认使用项目标识和本机临时签名。

## 检查与版本

在上述终端位置输入 `bash test.sh`，会依次检查计时结算、交易、存档兼容、习惯奖励、保存失败处理、周月统计、日历、屏幕位置和场景点击范围，并检查全部源码是否能够编译。测试使用临时存档，结束后自动清理。

源码位于 `Sources`，图像位于 `Resources`，规则检查位于 `Tests`。`Resources/Chibi` 保存桌宠姿势，`Resources/Game` 保存场景与食物，`Resources/Doll` 保存衣柜素材。

版本号记录在 `Resources/Info.plist`，更新记录见 [CHANGELOG.md](CHANGELOG.md)。维护者提交当前版本后运行 `bash publish.sh`，检查通过后将源码与对应 `v版本号` 标签推送到远端。每个标签保留当时的源码快照。
