# 炼金

炼金室在8级开放。每次选择1至5种不同材料，每种消耗1份，选择小火、中火或大火，并填写1至1440分钟的熬制时间。熬制随有效专注推进，暂停与休息冻结。开始时保存本次结果，完成后领取；材料在开始时扣除，失败也消耗材料。

## 特性与结果

每种材料具有1至3项特性。特性为各类作用提供权重，配料的权重相加，再按火候适配程度调整。作用按权重抽取，同一瓶内不会重复。

| 特性 | 作用权重 |
| --- | --- |
| 清润 | 露水5、促生1 |
| 促生 | 促生5、催芽1 |
| 催芽 | 催芽5、促生1 |
| 滋养 | 饲育5、催芽1 |
| 凝合 | 露水1、饲育1 |

每种材料有适宜火候、基础熬制时间和适用程度。组合的适宜时间为最长材料时间加每种额外材料2分钟。材料间没有共同特性的比例会降低适配分数，最多扣24分；火候每相差一级扣18分，按材料平均。

用时不足时，扣分为不足比例乘65；用时在适宜时间的100%至120%之间不扣分，超过120%的部分按比例乘32扣分。适配分减去火候与时间扣分后，品质基准限制在5至95，成功率为基准加8，限制在8%至98%。成功品在基准上下8分浮动，最终品质限制在1至100。

品质1至44抽1项作用、45至74抽2项、75至100最多抽3项；候选作用少时以候选数量为准。露水按品质每15分向上取整发放，促生按每20分向上取整增加分钟；催芽给予胡萝卜、小麦和番茄各1袋种子，品质65以上各2袋；饲育给予1袋饲料，品质80以上2袋。混合药剂全部作用满足使用条件时才一起消耗与生效。

## 配方与库存

炼金桌左侧的图画配方册可点击打开。商店出售6份配方，价格为20铜加每种材料10铜。成功制作的组合进入配方册，购买配方也会掌握对应组合。配方包含材料、火候和时间，可一键准备当前库存中已有的材料。

成品按配方、品质与作用组合分批保存。每瓶售价为“材料估价合计的65%加适宜分钟数的30%”乘品质比例，向下取整，最低1铜。已保存的单瓶报价随该批次保留。

已有固定配方药剂继续使用原有作用及报价；已经开始的固定配方熬制按原时长完成，与自由熬制共用一个坩埚。
